- Created a deep learning model combining Computer Vision and NLP, using PyTorch to integrate CNNs with LSTMs and Transformers, achieving a max BLEU-4 caption score of 11.0.
- Utilized beam search sampling, improving BLEU-4 score by 20%, resulting in higher quality generated captions.
- Implemented advanced data augmentation pipeline using spatial transformations and image distortions, multiplying dataset length by 5x, improving model robustness and reducing overfitting across diverse visual inputs.
- Implemented transfer learning using VGG16 trained on ImageNet, achieving 5% increase in convergence accuracy.
